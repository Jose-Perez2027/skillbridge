# SkillBridge final

Esta versión incluye:
- Sitio preparado para inglés y español mediante el botón EN/ES.
- Publicación de vacantes con campos en inglés y español.
- Preferencias de accesibilidad guardadas por cuenta: idioma, modo oscuro, alto contraste, modo lectura y tamaño de texto.
- Modo lectura por hover y foco de teclado, sin bloquear enlaces ni botones.
- Lectura para íconos comunes, imágenes, botones, enlaces y formularios.
- Reset de accesibilidad sin cambiar el idioma seleccionado.
- Configuración para Render + Aiven con Dockerfile, render.yaml y variables de entorno.

Antes de subir a internet, importar la base y ejecutar `database/migracion_accesibilidad_bilingue.sql` si las columnas no existen.
